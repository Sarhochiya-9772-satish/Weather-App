# Weather-App
A simple and responsive Weather App that fetches and displays real-time weather data for any city using a weather API.

## Features
1. Search by city name (case-insensitive).
2. Shows temperature, weather description, icon, humidity, wind speed, and sunrise/sunset times.
3. Error handling (city not found / network issues).
4. Loading state and keyboard support (press Enter to search).
5. Uses async/await and clean DOM updates.
6. Responsive, minimal UI

### How It Works
1.User enters a city name.
2.App sends a request to the weather API.
3.API returns weather data in JSON format.
4.The app extracts and displays relevant weather details.
5.API Used
